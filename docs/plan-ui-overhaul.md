# UI/UX 全面重构计划（2026-11-26）

> 依据用户裁决：结合项目职责与哲学重构 UI/UX；四个工作台统一信息架构；
> 项目源文件改为单一打包格式；主题要有活力（现在太暗）；Aqua 风格要真正落地
> （不能只加一层条纹）；下拉列表收缩；主页可适当改动。

## 1. 信息架构：四栏目（所有工作台统一）

每个工作台的内容区固定四栏目，**不再出现独立的"项目管理/IDE"模块**：

| 栏目 | 职责 | 事实源 | 设计面现状映射 |
| --- | --- | --- | --- |
| **呈现效果** | 渲染结果 / 可交互预览 | 由项目本体渲染 | `view=design`（画布）、`play`（演示） |
| **文档** | 需求/设计文档（人读） | 项目内 `docs/*.md` | `view=docs` |
| **规范** | 可校验规范（机器读） | 项目内 `spec.json` | `panel=spec` |
| **源码** | 源码本体（多文件=项目结构树，只展示源码结构） | 项目内 `source/**` | `view=source` |

- 源码栏的树**只包含源码文件**（不含 assets/artifacts），按目录层级展示；
  单文件项目就是一棵单节点树。
- 四栏是**同一项目的四个视角**，切换不改变项目；顶栏只保留项目切换与新建。
- 关键词：呈现效果（不是"画布"）、文档、规范、源码——文案统一。

## 2. 右侧栏：助手 + 检查（所有工作台统一）

右侧 NaN 栏固定两个 tab：

1. **助手**：聊天 / 任务执行（现有 ChatStream，不改）。
2. **检查**：人工微调细节。**参考设计面检查器的用法**，但按工作台适配元素与属性：

| 工作台 | 检查对象 | 属性（首批） |
| --- | --- | --- |
| 设计 | 画板 / 节点 | 现有（几何、文本、填充、描边、层级） |
| 3D | 节点 / 灯光 / 相机 | 变换、可见性、材质基础色/粗糙度、灯光强度/色温 |
| 视频 | 镜头 / 时间线条目 | 起止时间、时长、文本/样式、转场、音量 |
| 3D 视频 | 镜头 / 节点 | 起止时间、相机运动、节点变换 |
| 音乐 | 轨道 / 小节 / 音符 | 乐器、音量、静音、小节拍号、音符音高/时值 |

检查器统一骨架：**选择态（选中什么）+ 属性分组 + 行内编辑 + 保存反馈 + 未选中空态**。
保存必须走项目既有编辑出口（不绕过存储层）。

## 3. 项目源文件：单一打包格式（类 DDP）

现在设计项目是单个 `.ddp`，而 3D / 视频 / 音乐 / 3D 视频是目录散文件。改成**一处容器**：

```
nan.pack/1 容器（复用 DDP2 的 zstd + CRC32 字节纪律）
  kind:    design | three | video | video3d | music
  name:    项目名
  title:   标题
  docs:    文档正文（markdown）
  spec:    规范 JSON
  files:   源码文件表 { "src/scene.js": "...", "timeline.json": "..." }
```

- 扩展名按 kind 区分：`.ddp`（设计，兼容既有）/ `.n3d` / `.nvdo` / `.n3v` / `.nmu`。
- 目录形态仍可作为工作副本存在，但**对外交付与"单一事实源"是打包文件**；
  打开项目 = 解包到项目目录；保存 = 重新打包（原子写）。
- 既有目录项目：首次打开时**迁移打包**，迁移失败给可行动提示，不静默丢数据。
- 兼容：旧 `.ddp` 保持可读；新容器带版本号，未知版本显性拒绝。

## 4. 主题：活力化 + 真正 Aqua

### 4.1 深色主题（默认仍需可用）
- 抬亮层级：`bg 0xFF08090C → 0xFF101319`、`panel 0xFF11141B → 0xFF171C26`、
  `panel2 → 0xFF1E2533`，让层级靠明度而不是靠黑影。
- 提高强调色饱和与亮度：accent `0xFF7C8CFF → 0xFF5B8CFF`、accent2 `0xFFB58CFF → 0xFFC07BFF`；
  语义色（success/warn/danger）同步提亮。
- 文字对比度校验：正文 ≥ 4.5:1（令牌表 + 测试）。

### 4.2 Aqua（浅色）真正落地
不是"加一层条纹"，而是**材质系统**：
- **凝胶**用于：主 CTA、选中态胶囊、分段控件选中项、运输条按钮组、工具条高频动作；
  顶部高光 + 内发光 + 细边线，明确非毛玻璃。
- **窗口面**：细条纹底 + 顶部光泽渐变 + 深色软阴影；面板用白色 + 极细分隔。
- **窗口控件**：红/黄/绿口香糖球（标题栏左，已有组件）。
- **页签**：四栏目用 Aqua 分段胶囊（选中为凝胶蓝，未选中为白面）。
- 焦点环、减少动效、4.5:1 全部保留。

## 5. 下拉列表收缩
- 统一 `nonSelect` / 菜单：最大宽度受限（默认 ≤ 280，随锚点宽度自适应），
  行高紧凑（32），分组标题 11，不用全宽铺满；超长文本省略 + tooltip。
- 顶栏项目下拉、模型选择、主题选择、工作台内所有枚举下拉统一走该规格。

## 6. 主页
- 保留"一句话 → 文档 → 原型"主入口与作品集。
- 增补工作台入口卡（设计/3D/视频/音乐），与四栏目结构呼应；
- 视觉跟随新主题（活力化 + Aqua）。

# 设计系统与交互原则

## 视觉

- **暗色为主**：背景 `#08090C`，面板 `#11141B`，画布 `#0A0B0F`；
  品牌渐变 `#7C8CFF → #B58CFF → #FF9BD2`。
- **层级靠明度与留白，不靠边框堆叠**：线宽 1px，透明度 8% / 14% 两档。
- **画布是主角**：面板低对比、画板高对比白底 + 投影；选中态用品牌色 2px 环。
- **字体**：系统字体（macOS SF Pro / PingFang SC）；等宽用于 id、坐标、token 计数。
- **圆角**：控件 6–10，面板 12–16，画板 3（设计稿的"纸"）。
- **动效**：150–220ms ease-out；面板淡入上移 6px；尊重 reduce motion。

## 信息架构

- **左栏**：画板 / 图层 / 流程 / 最近项目；文档 / 规范 / 历史。
- **中栏**：画板页签 + 自由画布；缩放 HUD、flow 开关、LIVE 标识。
- **右栏**：NoN（时间线 + composer）与检查器（选中节点 / 画板）。
- **顶栏**：项目菜单、⌘K 命令条、运行胶囊、模型、设置。
- **状态栏**：脏态、rev、板/节点、Agent 状态、ctx / 缓存命中、模型、⌘K。

## AI Native 原则

1. **一句话起步**：Welcome 的大输入框就是主入口；示例 chips 降低冷启动成本。
2. **先文档后画布**：PLAN → BUILD 两阶段；文档页可在生成过程中实时看到写入。
3. **执行可见**：工具调用逐条进时间线（参数、耗时、结果/错误），终态卡明确"结束没有、
   正常与否"。
4. **画布实时**：每个变更 op 发 `preview`，Flutter 节流 render，用户看着页面长出来。
5. **可打断**：运行胶囊可停止；停止在当前步骤结束后生效，不丢已提交工作。
6. **可撤销**：所有提交进历史栈；Agent 终态也作为一次提交。
7. **选中即上下文**：选中节点后 "让 NoN 改" 直接带着该节点进入对话。
8. **键盘优先**：⌘K、⌘S、⌘Z/⇧⌘Z、⌘1–4、⌘0、⌘/；所有操作都有可见入口。

## 人因细节

- 点击目标 ≥ 24px；文字对比 ≥ 4.5；焦点环始终可见。
- 错误说清"发生了什么 + 下一步"，不静默失败。
- 破坏性操作（删除画板/节点、退出未保存）二次确认。
- 长文本折叠但不截断事实链；轨迹是全局唯一时间线，不随视图切换清空。
- 状态栏复位语义：过程态结束必须回到"就绪"，不能让绿卡完成而底部还写"生成中"。

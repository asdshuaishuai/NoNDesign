# 视频工作台人工验收（代码动画）

> 用户裁决 2026-11-18：**视频模块是代码实现的动画，不是渲染成 mp4**。
> 时间线脚本 + 规范编译成算式，每一帧由 `VideoDocument.frameSvg(t)` 现场生成、
> 在应用内实时播放；mp4 导出暂时屏蔽（工作台里没有渲染入口）。
>
> 自动化测试能证明「帧随时间前进了、暂停停住了、拖动跳帧了、坏帧不崩」，
> 但证明不了真机上的观感（拖影、卡顿、高分屏清晰度）。这份清单就是为那一步
> 准备的。未勾选的项视为未验收。

## 1. 为什么需要人工验收

代码动画没有「文件」可以抽查：画面是算出来的。widget 测试用假时钟推进，
能锁住状态机与帧号，但以下事实只有在真机上才看得见：

- 播放时画面真的在动（不是永远停在第一帧），且帧率稳定；
- 拖动进度条后画面**立刻**跳到对应时刻，不是等下一次 tick；
- 高分屏 / 小窗口下矢量帧清晰、不模糊、不越界；
- 连续播放长动画（≥ 60 s）不发热卡顿、不泄漏 timer。

自动化已覆盖的部分（`flutter test`）：

- `test/video_animation_surface_test.dart`：首帧渲染、播放推进时间与帧号、
  暂停停止推进、拖动 seek、循环开关、坏帧只显示人话提示；
- `test/video_workspace_test.dart`：动画优先的主面、脚本编辑、规范对照、
  没有渲染/导出按钮、艺术架 mp4 播放面；
- `test/video_service_test.dart`：时间线/规范编译、机械对照、时间格式。

## 2. 前置条件

- macOS 13+（主开发目标），已构建可运行的应用（`flutter run -d macos`
  或 `flutter build macos --debug`）。
- **不需要**本机外部组件：代码动画不 spawn `resvg` / `ffmpeg`。若某台机器
  还装着它们，也与本模块无关。

## 3. 验收步骤

### A. 动画播放 / 拖动（核心人工项）

1. 打开应用 → 左侧工作区切换到「视频」（或 ⌘6）。
2. 默认选中「物理 · 斜面摩擦力」，主面应已显示第 1 帧（不自动播放）。
3. 点 ▷ 播放，观察画面变化与时间码前进；点 ⏸ 暂停，再点 ▷ 继续。
4. 把时间轴拖到约 25%、50%、90%，各停一次观察画面。
5. 点 ⟲ 回到片头，播放到结尾；打开 ⟳ 循环再播一遍。

| 检查项 | 期望 |
|---|---|
| 首帧 | 进入工作台就有画面（第 1 帧），不是空白或转圈 |
| 播放 | 画面连续变化；时间码 `mm:ss.SSS` 与 `frame n/N` 同步前进 |
| 暂停/继续 | 停在当前帧；继续从当前帧播，不跳回 0 |
| 拖动 seek | 松手即显示目标时刻的画面，时间码与帧号一致 |
| 结尾 | 停在最后一帧（循环开启时从头继续） |
| 清晰度 | 矢量帧在高分屏清晰，画面框内不越界、不变形 |

### B. 脚本与对照

1. 点「编辑脚本」，改动时间线里一段时长，确认保存后画面时长变化。
2. 故意写错一个符号（如引用未声明的变量），保存 → 应出现「规范对照」失败
   的一句话说明；展开「技术详情」能看到原始诊断。
3. 改回正确内容，确认失败提示消失、画面恢复正常。
4. 切到另一个「标杆示例」，确认画面与时长一起换掉。

| 检查项 | 期望 |
|---|---|
| 脚本保存 | 时长/帧号随脚本变化，不要求重启工作台 |
| 坏脚本 | 只显示人话（如「先补齐规范再看画面」），原始码只在折叠详情里 |
| 好脚本 | 失败提示清除，画面恢复 |
| 示例切换 | 画面、时长、规范结果同步更新 |

### C. 艺术架里的既有视频（mp4 产物）

1. 从「作品集」的视频架打开一个**已存在的** mp4 产物。
2. 播放面应正常播放；返回按钮文案为「返回创作台」。
3. 返回后工作台回到代码动画面，且示例文档仍可播放。

| 检查项 | 期望 |
|---|---|
| 既有产物 | 正常播放（这是播放文件，不是代码动画） |
| 返回 | 「返回创作台」回到动画面，不丢当前示例 |
| 缺失文件 | 显示「无法播放：这个视频文件不在了或无法读取」；「复制路径」可用 |

### D. 手机 / 平板

| 检查项 | 期望 |
|---|---|
| 进入视频工作台 | 可进入；主面直接是代码动画（不依赖桌面组件） |
| 播放 / 拖动 | 与桌面一致（触摸拖动时间轴可用） |
| 渲染/导出 | **不存在**该入口（全平台一致，不是「点了才提示」） |
| 脚本编辑 | 本地校验通过/失败都有明确一句话 |
| 竖屏 / 横屏 | 动画面与脚本面板上下/左右自适应，不溢出 |

### E. Linux / Windows

| 检查项 | 期望 |
|---|---|
| 代码动画 | 正常播放（纯 Dart + 矢量绘制，无平台专有依赖） |
| 既有 mp4 产物 | 无内嵌播放器实现 → 显示「当前平台不支持应用内视频播放」+ 路径 |

## 4. 已知限制（不要当成缺陷）

- **不导出成片**：mp4 渲染入口已按用户裁决暂时屏蔽；`VideoService` 的渲染
  代码保留给后续恢复，但界面上没有任何入口。
- **环③ 视觉评审（抽帧给视觉模型打分）不在本模块**：工作台只做环②机械对照。
- **既有 mp4 播放依赖平台播放器**：Linux/Windows 无应用内实现，降级为路径提示。
- 旧存档里的渲染任务号在进入工作台时会被静默清除（已无对应界面）。

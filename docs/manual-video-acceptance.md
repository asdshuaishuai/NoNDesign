# 视频播放 / seek 人工验收（macOS）

> 批次 08（视频本地工作台）的验收记录 + 可重复执行的验收脚本。
> 自动化测试能证明「文件被正确装载、控制器参数正确、错误覆盖层会出现」，
> 但**证明不了真机上视频真的在播、拖动进度条真的在 seek**——这一份就是为
> 那一步准备的人工清单。未勾选的项视为未验收。

## 1. 为什么需要人工验收

历史遗留问题（`docs/round7-residuals.md` S2）：旧实现的 widget 测试只断言
播放 URL、WebView 创建参数与错误覆盖层，**没有任何一项观察到真实播放器在
播放、以及拖动进度条后的画面变化**。批次 08 把播放面从「服务端取流」改成
「本机文件直读」，WebKit 的自动播放策略与本地文件读取权限都换了路径，必须
在真机上重新看一遍。

自动化能覆盖的部分（已在本机执行，见 §5）：

- 逐帧画面与旧管线逐字节一致（15 个时间点，`scripts/wf/video_golden_check.py`）；
- 本机渲染组件存在且能出片（`--dart-define=VIDEO_RENDER_GATE=true`）；
- 播放面装载的是本机文件、创建参数放开自动播放、主帧失败有覆盖层
  （`app/test/shelf_video_player_test.dart`）。

自动化**不能**覆盖的部分（本文的人工清单）：

- 视频真的在播放（有画面、有时间轴前进）；
- 拖动进度条能 seek（画面跳到对应位置，进度与时间码一致）；
- 播放结束、暂停、再次播放的状态正确；
- 删除文件后重新打开，覆盖层与「复制路径」的实际交互。

## 2. 前置条件

```bash
# 渲染组件（macOS 本机实测路径）
which ffmpeg    # /opt/homebrew/bin/ffmpeg
which resvg     # /opt/homebrew/bin/resvg（rsvg-convert 也可）
```

- macOS 13+，已构建可运行的桌面应用（`flutter build macos --debug` 或
  `flutter run -d macos`）。
- 本机视频产物目录：`~/Documents/NoNDesign/videos/<任务号>/frames.mp4`。

## 3. 验收步骤

### A. 出片（桌面，约 1–2 分钟）

1. 打开应用 → 左侧栏进入「视频工作台」。
2. 默认选中「物理 · 斜面摩擦力」，确认右侧出现「规范对照 · 通过」。
3. 帧率保持 10 → 点「渲染（后台）」。
4. 观察进度条从 0 走到 100%，完成时出现「渲染完成（N 帧）」通知。
5. 预览区出现帧缩略图条带；点「播放成片」。

| 检查项 | 期望 |
|---|---|
| 渲染进度 | 单调递增，不跳回 0；渲染期间「渲染」按钮禁用 |
| 完成通知 | 胶囊通知在左上角，2–3 秒自动消失；通知历史里可回看 |
| 帧条带 | 至少 24 格缩略图，无破图占位 |
| 成片路径 | 形如 `~/Documents/NoNDesign/videos/video-<时间戳>-<n>/frames.mp4` |

### B. 播放 / seek（核心人工项）

1. 在「播放成片」的播放面里点播放。
2. 播放 2 秒后暂停，再播放。
3. 把进度条拖到约 50%，再拖到约 90%。
4. 拖回开头，播放到结束。
5. 点「返回渲染台」，再从左侧「艺术架」→「视频」里打开同一产物。

| 检查项 | 期望 |
|---|---|
| 播放 | 有画面变化，时间轴前进；无静音拦截（无需点第二下） |
| 暂停/继续 | 停在当前帧，继续从当前帧播 |
| 拖动 seek | 画面跳到目标位置；松开后从该位置继续 |
| 结尾 | 停在最后一帧，不黑屏、不自动退出 |
| 二次打开 | 艺术架入口与工作台入口播放行为一致 |
| 点击/键盘 | 播放面内点击不穿透到画布；⌘1 返回设计正常 |

### C. 失败路径

1. 关闭应用，把产物文件改名（或在终端删除）。
2. 重新从艺术架打开该产物。

| 检查项 | 期望 |
|---|---|
| 覆盖层 | 显示「无法播放：这个视频文件不在了或无法读取」 |
| 出口 | 「复制路径」可用；桌面端「在文件夹中显示」可用 |
| 不崩 | 应用不崩溃，返回渲染台/切视图正常 |

### D. 手机 / 平板（iOS / Android，人工）

| 检查项 | 期望 |
|---|---|
| 视频工作区入口 | 可进入；示例与对照检查在本地完成 |
| 点「渲染」 | 立即提示「视频导出只在电脑上可用」，不创建任务、不转圈 |
| 编辑脚本 | 粘贴时间线 + 规范，能完成本地校验（通过/失败都有明确一句话） |
| 播放既有视频 | 艺术架里的 mp4 能播放（本机文件） |
| 「在文件夹中显示」 | 不出现该入口（只有「复制路径」） |

### E. Linux / Windows（人工，可选）

| 检查项 | 期望 |
|---|---|
| 应用内播放 | 没有内嵌 WebView 实现 → 显示「当前平台不支持应用内视频播放」+ 路径 |
| 渲染 | `resvg`/`ffmpeg` 在 PATH 上时可以出片；缺失时提示「缺少组件」而不是静默失败 |

## 4. 已知限制（不要当成缺陷）

- **移动端不渲染**：手机/平板不能 spawn 外部程序，视频编码永久不可用；只保留
  脚本编辑、机械对照与既有视频播放。
- **环③ 视觉评审（抽帧给视觉模型打分）只在桌面**：移动端没有抽帧+视觉链路，
  工作台只做环②机械对照。
- **Linux/Windows 无应用内播放**：`webview_flutter` 没有这两个平台的实现。
- **渲染组件是外部程序**：macOS 实测 `/opt/homebrew/bin/{ffmpeg,resvg}`；
  Windows/Linux 需要用户自行安装（或在后续版本随包分发）。
